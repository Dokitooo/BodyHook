===============================================================================
  BodyHook CHEAT SHEET  -  custom content inside pngXXXX.iff
===============================================================================

BASICS
------
  pngXXXX.iff  = a player's cyberface file. XXXX = his CFID in the roster.
  Everything below goes INSIDE that file, as extra rows.
  Only that player uses it. Everyone else is unaffected.

  FileIDs are written the way RED MC shows them (4 bytes, left to right).
  In a hex editor they appear reversed. Ignore that; use RED MC's form.


GENERAL STEPS (RED MC)
----------------------
  1. Open  pngXXXX.iff  in RED MC.
  2. Clone an existing row of the RIGHT TYPE:
        SCNE row  -> for bodies, jerseys, shorts
        TXTR row  -> for leg tattoos and accessory textures
  3. Import your file into the cloned row:
        body / jersey / shorts  -> import the model (.rmce)
        leg tattoo / accessory  -> import the texture (.dds)
  4. Set the row's FileID to one from the tables below.
  5. Save, put the png in the game folder, done.
  6. (Optional) check it:  python tools\iff_tool.py info pngXXXX.iff

  * Use NONMOVING (static) models. Copy the row from a NONMOVING
    cloth_u / cloth_v / cloth_wishbone .iff.

  NORMAL MAPS: add a TXTR row with the Normal map FileID to the player's png.
  The texture and the normal map are independent: a png can have only the
  texture, only the normal map, or both. Anything missing comes from
  global.iff. Normal maps are DXT5 (use the normal map from global.iff as the
  starting point: export it in IFF Mod Studio, edit, import).
  The normal map FileID is always the texture's name with "_n" added
  (elbowsleeve 04 63 3A 86 -> elbowsleeve_n 7D 25 FD 27). The headband is the
  exception: unif_headband_normal 57 79 DB B0.

  * Some textures are shared by several accessories (6A EF 61 FE is used by
    four bands). A custom one changes all of them for that player.
  * Any size works; keeping the size of the original is safest.
  * Changes show up without restarting the game: save the png, then close
    and reopen Edit Player (or reload the player).
  * Combinations: with AllowCombinations=1 every equipped slot is drawn,
    e.g. arm sleeve + short-sleeve shirt, leg sleeve + knee pad.

6) COACH POLO   (texture rows in global.iff, row type: TXTR)
------------------------------------------------------------
  OFF by default. With [CoachPolo] Enabled=1 coaches wear the polo instead of the
  suit jacket. ShowArms=1 = coaches in a suit show whole arms (never players).
  Name                     FileID
  coach_suit_colorize      F0 75 27 59   <- polo colour/pattern (tinted with team colours)
  coach_suit_normal        A5 FD 6D 9F   <- polo normal map

  * Paint on the POLO layout (hi_body part 0-18), keep the size/format of
    the original rows, and replace them in global.iff with RED MC.
  * Or add rows with your own FileIDs and set Texture= / NormalMap= in the ini.


7) TEAM COLOUR SOCKS   (sock texture rows, row type: TXTR)
------------------------------------------------------------
  Accessory textures are colour MASKS. Each channel is painted with one colour:
      RED channel   -> colour 1      GREEN channel -> colour 2      BLUE channel -> colour 3
  Pure red paints with colour 1, pure green with colour 2, pure blue with colour 3,
  and the brightness of the channel is the shading. Stock socks are painted red only;
  the striped long socks are blue with red stripes.

  With [TeamColorSocks] Enabled=1 every sock type gets:
      Style=1   red = TEAM 1   green = TEAM 2   blue = sock colour (white/black from the uniform)
      Style=2   red = sock colour   green = TEAM 1   blue = TEAM 2
  Style 1 = same as the striped long socks: stock socks turn Team 1 straight away;
  paint parts blue to keep them white/black. Style 2 keeps stock socks white/black
  and only the green/blue parts you paint take the team colours.
  Striped long socks always keep their stock behaviour.

  Name                     FileID
  ankle socks              C4 52 02 5A
  short socks              51 1C F1 31
  short double socks       9E EE 8F 94
  medium socks             7B 24 B4 A0
  medium double socks      B4 D6 CA 05
  medium long socks        45 E2 62 04
  long socks               BC 03 E9 07
  striped long socks       81 DA 22 CA   (stock: red = Team 1, blue = white)

  * Paint with pure red / green / blue (DXT1, same size as the original row) and
    replace the row in global.iff for everyone, or add it to a player's png for
    that player only (it is an accessory texture, see section 5).
  * Leave a sock type out of Socks= in the ini to keep it stock.


8) HAIR STYLES   (whole-png variants, no FileIDs needed)
------------------------------------------------------------
  png19600.iff           <- Original
  png19600_hair1.iff     <- shows as "hair1"
  png19600_anyname.iff   <- shows as "anyname"
  Edit Player > Body & Head > Hair Style (regular players only, below Height/Weight).
  Pick one, then back out and reopen the player to see it. Saved (when the game saves the roster) per roster in BodyHook\rosters\<roster>.ini
  (kept after restarting the game).


9) NBA PATCH   (unif_nbapatch  0D AE 36 BF, row type: TXTR)
------------------------------------------------------------
  [NBAPatch] HeadbandOnly=1: this texture shows on headbands (Headband Logo) only.
  Jerseys, shorts, socks, menus: no NBA patch. Edit the row in global.iff to change the
  headband logo for everyone.
